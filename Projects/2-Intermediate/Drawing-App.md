# App de Desenho

**Nível:** 2-Intermediário

Crie arte digital em um canvas na web para compartilhar online e também exportar como imagens.

## Histórias de Usuário

-   [ ] O usuário pode desenhar em um `canvas` usando o mouse
-   [ ] O usuário pode mudar a cor
-   [ ] O usuário pode mudar o tamanho da ferramenta
-   [ ] O usuário pode pressionar um botão para limpar o `canvas`

## Funcionalidades Bônus

-   [ ] O usuário pode salvar a arte como uma imagem (formatos `.png`, `.jpg`, etc)
-   [ ] O usuário pode desenhar diferentes formas (`retângulo`, `círculo`, `estrela`, etc)
-   [ ] O usuário pode compartilhar a arte nas redes sociais
