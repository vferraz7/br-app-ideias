# Chrome Theme Extension

**Nível:** 2-Intermediário

Construa sua própria extensão de tema personalizado do Chrome. Você também
pode adicionar a funcionalidade filtro de luz noturna (também conhecido
como filtro de luz azul) que ligará automaticamente durante a noite para
que os olhos do usuário não fiquem cansados enquanto codifica a noite
inteira or maratonas de Netflix 😛

- Como extensões Chrome funcionam (nos bastidores).
- Entendimento básico de HTML/CSS, JS, JSON é necessário.

## Histórias de Usuário

- [ ] O usuário pode criar um tema de acordo com sua própria preferência
    de cores
- [ ] Isso beneficiará extremamente pessoas com daltonismo.
- [ ] O usuário pode instalar and defini-lo como tema padrão.

## Funcionalidades Bônus

- [ ] Implantar extensão na Chrome Store
- [ ] Adicionar um botão de alternância para controlar a funcionalidade
    de filtro de luz manualmente
- [ ] Criar a mesma extensão para múltiplos navegadores como firefox,
    etc.
