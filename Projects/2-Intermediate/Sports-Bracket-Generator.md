# Gerador de Chaveamento Esportivo

**Nível:** 2-Intermediário

Seja seu esporte principal futebol, beisebol, críquete, ou Esports competitivos, acompanhar o progresso do seu time favorito durante torneios é uma atividade apreciada por muitos.

O acompanhamento do progresso do time é tradicionalmente feito usando um diagrama de árvore horizontal mostrando todas as partidas iniciais no lado esquerdo. Ao final de cada partida, o vencedor avança para a próxima rodada do torneio junto com o vencedor da partida adjacente. Colunas no diagrama são usadas para representar cada rodada e contêm metade dos times na coluna adjacente à esquerda e o dobro de times que a coluna adjacente à direita. O número de times em cada coluna diminui da esquerda para a direita até a última rodada (coluna) conter o vencedor final do torneio.

O Gerador de Chaveamento Esportivo automatiza o processo de criar este tipo de gráfico desenhando-o em uma janela do navegador para aliviar o usuário de ter que desenhá-lo à mão.

## Histórias de Usuário

-   [ ] O usuário pode inserir o nome do torneio
-   [ ] O usuário pode inserir as datas de início e término do torneio
-   [ ] O usuário pode inserir o número de times competindo no torneio
-   [ ] O usuário pode ver um aviso se a data de início ou término for inválida
-   [ ] O usuário pode ver um aviso se um número ímpar de times competidores for inserido

## Funcionalidades Bônus

-   [ ] O usuário pode inserir os nomes dos times competidores para cada partida
-   [ ] O usuário pode inserir a data para cada partida
-   [ ] O usuário pode inserir o placar final para cada partida
-   [ ] O usuário pode esperar que estes dados persistam entre sessões
