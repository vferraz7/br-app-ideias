# Weather App

**Nível:** 1-Iniciante

Uma aplicação de tempo para obter a temperatura, condição climática e se
é dia ou noite de uma cidade específica usando `accuweather`. Uma API
gratuita de tempo.

## Histórias de Usuário

- [ ] Insira o nome de uma cidade no campo de `entrada`.
- [ ] Ao pressionar enter, o usuário submite o nome da cidade que
    atualiza o `DOM` com a temperatura, condição climática, imagem de
    dia ou noite and ícone de condição climática.

## Funcionalidades Bônus

- [ ] Ao fechar a janela do navegador o nome da cidade será armazenado
    no localStorage and quando o usuário retornar, o nome será
    recuperado para fazer uma chamada à API para atualizar o `DOM`.
