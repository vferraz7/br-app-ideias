# Slider Design

**Nível:** 1-Iniciante

Exiba múltiplas imagens usando um slider / carrossel.

## Histórias de Usuário

-   [ ] O usuário pode ver um slider exibindo múltiplas imagens a cada `x`
    segundos
-   [ ] O usuário pode clicar nos botões `anterior` and `próximo` and the
    slider exibirá a imagem correspondente

## Funcionalidades Bônus

-   [ ] Adicione animação aos slides
-   [ ] Adicione texto sobre os slides
-   [ ] Crie um efeito 3D

## Links e Recursos Úteis

-   [Unsplash](https://unsplash.com/) para imagens gratuitas
