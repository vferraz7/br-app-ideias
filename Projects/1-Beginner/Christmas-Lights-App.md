# Christmas Lights

**Nível:** 1-Iniciante

A aplicação ChristmasLights conta com seus talentos de desenvolvimento para criar
um display de luzes hipnotizante. Sua tarefa é desenhar sete círculos coloridos
em uma linha e com base em um temporizador alterar a intensidade de cada círculo. Quando
um círculo é iluminado, seu antecessor retorna à intensidade normal.

Isso simula o efeito de uma string de luzes ondulantes, similar às
exibidas durante as Festas de Natal.

## Histórias de Usuário

-   [ ] O usuário pode pressionar um botão para iniciar e parar o display
-   [ ] O usuário pode alterar o intervalo de tempo que controla a mudança de intensidade

## Funcionalidades Bônus

-   [ ] O usuário pode selecionar a cor usada para preencher cada círculo
-   [ ] O usuário pode especificar o valor de intensidade
-   [ ] O usuário pode alterar o tamanho de qualquer círculo na linha
-   [ ] O usuário pode especificar o número de linhas a serem incluídas no display. De
        uma a sete linhas podem ser escolhidas
