# Border-radius Previewer

**Nível:** 1-Iniciante

A propriedade border-radius pode ter múltiplos valores alterados. Visualize como a forma fica enquanto altera esses valores.

## Histórias de Usuário

-   [ ] O usuário pode ver uma caixa com a propriedade `border-radius` aplicada
-   [ ] O usuário pode alterar os 4 valores de `border-radius` aplicados à caixa (topo-esquerdo, topo-direito, inferior-esquerdo, inferior-direito)
-   [ ] O usuário pode copiar o CSS resultante para a área de transferência

## Funcionalidades Bônus

-   [ ] O usuário pode alterar todos os 8 valores possíveis do border-radius para criar uma forma complexa
