Para este projeto, haverá três entradas obrigatórias para validação:
- A primeira exigiria que o usuário insira cinco (5) letras maiúsculas, seis (6) símbolos e dois hífens (-) em qualquer ordem. Isso poderia ser usado como senha.
- A segunda que poderia ser usado como nome de usuário exigiria que o usuário
  insira letras sem espaços
- A terceira que poderia ser usado como endereço de email exigiria que o
  usuário insira apenas endereços de email do gmail (...@gmail.com).

## Histórias de Usuário

-   [ ] O usuário deve ser notificado de quaisquer entradas inválidas através de
    mensagens de erro exibidas no formulário.
-   [ ] O botão de envio do formulário nunca seria executado até que todas
    as entradas sejam validadas.
