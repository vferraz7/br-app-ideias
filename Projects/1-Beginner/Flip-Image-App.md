# FlipImage

**Nível:** 1-Iniciante

É importante que Desenvolvedores Web entendam os fundamentos de manipulação
de imagens já que aplicações web ricas dependem de imagens para agregar valor
à interface do usuário e experiência do usuário (UI/UX).

O FlipImage explora um aspecto da manipulação de imagens - rotação de imagem.
Este app exibe um painel quadrado contendo uma única imagem apresentada em uma
matriz 2x2. Usando um conjunto de setas cima, baixo, esquerda, e direita
adjacentes a cada uma das imagens, o usuário pode girá-las vertical ou
horizontalmente.

Você deve usar apenas HTML, CSS, and Javascript nativos para implementar este app.
Pacotes e bibliotecas de imagem não são permitidos.

## Histórias de Usuário

-   [ ] O usuário pode ver um painel contendo uma única imagem repetida em uma matriz 2x2
-   [ ] O usuário pode girar qualquer uma das imagens vertical ou horizontalmente usando um conjunto de setas cima, baixo, esquerda, e direita ao lado da imagem

## Funcionalidades Bônus

-   [ ] O usuário pode alterar a imagem padrão inserindo a URL de uma imagem diferente em um campo de entrada
-   [ ] O usuário pode exibir a nova imagem clicando em um botão 'Exibir' ao lado do campo de entrada
-   [ ] O usuário pode ver uma mensagem de erro se a URL da nova imagem não for encontrada
