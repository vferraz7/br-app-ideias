## Guia de Contribuição

Este guia ajudará a garantir que você tenha uma forma simples e eficaz de contribuir para este projeto.

-   Se você quiser propor uma nova Ideia de App, por favor, use o [Guia de Exemplo](./Example%20Guide.md) como template base.
-   Antes de criar um Pull Request, verifique se sua sugestão já não foi adicionada ao projeto. Você pode submeter uma atualização se acredita que melhora uma ideia existente.
-   Certifique-se de conferir sua ortografia e gramática.
-   Crie um PR individual para cada sugestão.

Obrigado por dedicar seu tempo para melhorar este projeto! ^\_^
